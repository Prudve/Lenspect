# Data Directory

Contains realistic mock data mirroring actual Legal Metrology (Packaged Commodities) Rules, 2011 declarations:
- Mandatory declarations: MRP, Net Quantity, Date of Manufacture/Packing, Manufacturer Name & Complete Address, Consumer Care Details, Country of Origin, Common/Generic Name.
- Mock inspections from field inspectors with extracted OCR fields, confidence scores, pass/fail status, and cited rule clauses.
